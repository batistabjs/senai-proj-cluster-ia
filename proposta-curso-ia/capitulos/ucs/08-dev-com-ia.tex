\section{Desenvolvimento de Software Inteligente com Inteligência Artificial}

\textbf{OBJETIVO GERAL:}

Desenvolver competências para projetar, desenvolver, testar, implantar e manter aplicações inteligentes utilizando Inteligência Artificial, aplicando princípios modernos de Engenharia de Software, Arquitetura de Sistemas, APIs, Microsserviços, DevOps, DevSecOps, Computação em Nuvem e integração com Grandes Modelos de Linguagem (LLMs) e Agentes Inteligentes.

\textbf{CARGA HORÁRIA:} 140 horas

\textbf{FUNÇÃO:}

Desenvolver sistemas computacionais baseados em Inteligência Artificial, Análise Preditiva e Ecossistemas IoT, atendendo às normas de qualidade corporativas, robustez metodológica, governança de dados e arquitetura segura.

\textbf{SUBFUNÇÕES:}

\begin{itemize}
\item Projetar arquiteturas de software para aplicações inteligentes.
\item Desenvolver aplicações Full Stack integradas com Inteligência Artificial.
\item Desenvolver APIs para integração de serviços inteligentes.
\item Implantar aplicações em ambientes Cloud.
\item Automatizar processos utilizando DevOps e DevSecOps.
\end{itemize}

\textbf{PADRÕES DE DESEMPENHO:}

\begin{itemize}
\item Levantar requisitos para aplicações inteligentes.
\item Modelar arquiteturas escaláveis.
\item Desenvolver APIs REST para integração com modelos de IA.
\item Desenvolver interfaces para aplicações inteligentes.
\item Integrar aplicações com Grandes Modelos de Linguagem.
\item Automatizar testes e deploy.
\item Implantar aplicações em ambientes Cloud.
\item Aplicar princípios de segurança durante todo o ciclo de desenvolvimento.
\end{itemize}
