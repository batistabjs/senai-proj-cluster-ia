\section{Perfil do Egresso}

Ao concluir o curso, o egresso será capaz de:
\begin{itemize}
    \item Compreender os fundamentos matemáticos, computacionais e estatísticos da Inteligência Artificial.
    \item Desenvolver aplicações utilizando Python.
    \item Desenvolver pipelines de Engenharia de Dados.
    \item Construir modelos de Machine Learning.
    \item Construir modelos Deep Learning.
    \item Desenvolver aplicações utilizando Grandes Modelos de Linguagem (LLMs).
    \item Elaborar Engenharia de Prompt.
    \item Elaborar Engenharia de Contexto.
    \item Desenvolver sistemas utilizando RAG.
    \item Desenvolver Agentes Inteligentes.
    \item Desenvolver Sistemas Multiagentes.
    \item Integrar aplicações utilizando MCP.
    \item Desenvolver aplicações utilizando LangGraph.
    \item Desenvolver aplicações utilizando CrewAI.
    \item Desenvolver aplicações utilizando OpenAI Agents SDK.
    \item Desenvolver aplicações Full Stack integradas com IA.
    \item Desenvolver APIs Inteligentes.
    \item Desenvolver soluções de Visão Computacional.
    \item Desenvolver soluções IoT e IIoT.
    \item Implantar soluções em Cloud Computing.
    \item Aplicar MLOps e LLMOps.
    \item Monitorar modelos de IA.
    \item Aplicar IA Responsável, segurança, LGPD e governança.
    \item Liderar projetos de desenvolvimento de soluções inteligentes.
\end{itemize}
